# QC review findings (2026-10-10)

Read-only bug review of the repo at `de6efe9`, run before the QC fix pass. It reported only issues
not already in `docs/AUDIT.md`. Each finding was evidenced by a code citation or a small in-memory
reproduction; ones marked *suspected* were found by code reading only. Line numbers refer to that
commit and may have moved.

Test suite at review time: 370 passed, 0 failed.

## Status legend

- **Fixed**: fixed in `65c3bf2` (QC pass) or later, with a regression test.
- **Partly fixed**: see the note.
- **Open**: not fixed yet.

## Findings

| ID | Sev | Where | Defect | Status |
|---|---|---|---|---|
| QC-1 | High | `pipeline/windowing.py` `build_sequences`; `models/forecast.py` `latest_sequence(s)_batch` | Windows exist only for (host, 10 s slot) pairs that have flows, so "12 consecutive windows" and the K-step horizon can span large time gaps. Sampled: 82.9% of v1 test sequences and 3.2% of v2 contain a gap (max 8.6 h on v1). | Partly fixed: opt-in `windowing.require_contiguous_windows` (default off), `sequence_gap_stats` in build metadata, `input_contiguous` in `/forecast/predict`. Retraining with the option on is an open decision. |
| QC-2 | High | `models/baseline_lr.py` `_RestrictedUnpickler` | Allowlist matched module prefix only; a protocol-4 pickle with a dotted name reached arbitrary callables. | Fixed: exact (module, name) allowlist, dotted names rejected; same hardening in `pipeline/graph_builder.py`. |
| QC-3 | Med | `eval/metrics.py` `lead_time_metrics` | Alarms at or after onset counted as detections with negative lead time; miss rate understated. | Fixed: only alarms strictly before onset count; on-time and late alarms reported separately. Earlier lead-time figures are not comparable and need a re-run. |
| QC-4 | Med | `eval/metrics.py` `stage_metrics` | Macro precision/recall/F1 averaged over true plus predicted labels, not over the classes present in `y_true`. | Fixed. |
| QC-5 | Med | `models/audit_ledger.py`; ledger endpoints in `app/server.py` | Unlocked read-append-save; non-atomic save. Concurrent requests lose entries; a crash can truncate the ledger. | Fixed: process-wide lock, temp file plus `os.replace`. Single-process only. |
| QC-6 | Med | `models/audit_ledger.py`; `/system/status` | A malformed or extra-key ledger line raised, turning tamper evidence into an HTTP 500 that broke the dashboard load. | Fixed: loader reports not-intact with the first bad line; status returns `ledger_intact: false`. |
| QC-7 | Low-Med | `models/audit_ledger.py` `verify_integrity` | Docstring claimed truncation detection; tail truncation is not detected. Probabilities hashed at 6 decimals. | Partly fixed: docstring corrected. No external head-hash anchor. |
| QC-8 | Med | `app/api.py` `dispatch_webhook` | SSRF guard validates the URL, then `requests.post` re-resolves DNS and follows redirects; `host:port` allowlist entries never match. *Suspected* for exploitation. | Open. The service is off by default. |
| QC-9 | Med | `app/service.py` `load_backend` | `except Exception` swallowed every load error (schema mismatch, corrupt file, OOM) and cached it as "no checkpoint" until restart. | Partly fixed: bundle mode raises instead. Config mode unchanged. |
| QC-10 | Med | `scripts/stream_consumer.py` | Each 100-flow batch windowed separately (duplicate partial windows); posts to a route that does not exist on `app/server.py`; response status unchecked. | Superseded: script marked deprecated; `app/live.py` replaces it. |
| QC-11 | Low-Med | `common/config.py` `resolve_path` | `PHOENIX_*_DIR` env overrides are global, so every dataset config resolves to the same checkpoint dir. | Partly fixed: bundles ignore the overrides. Config mode unchanged. |
| QC-12 | Low | `app/server.py` upload handler | Whole upload read into RAM before the 300 MB check; Scapy pcap parsing builds one dict per packet. *Suspected* memory cost. | Open. |
| QC-13 | Low | `frontend/src/pages/Dashboard.jsx` | Reads `stage_disclosure_note` but the API key is `stage_disclosure_notes`; hardcodes `(idx+1)*10` s instead of `step_seconds`. | Open. |
| QC-14 | Low | `frontend/src/pages/Dashboard.jsx` | Selected host, forecast and explanation panels not cleared on dataset switch or upload; no stale-response guard. *Suspected* UI behaviour. | Open. |
| QC-15 | Low | `app/server.py` `what_if_forecast` | `scale=NaN` accepted, then the JSON response raises (HTTP 500). | Open. |
